DETAIL

Ringkasan pembelajaran.

01

PERTEMUAN 1

Pengenalan Website

Pengenalan website dan gambaran umum pemrograman web

Pada pertemuan ini pembelajaran dilaksanakan melalui Zoom Meeting. Materi berisi pengenalan website, gambaran umum pemrograman web, serta teknologi dasar yang akan digunakan selama perkuliahan.

Hasil pembelajaran

Memahami konsep awal website dan mengenal HTML, CSS, serta JavaScript sebagai teknologi dasar pengembangan web.

02

PERTEMUAN 2

HTML Dasar

Struktur dan elemen dasar HTML

Mempelajari HTML sebagai bahasa markup untuk membangun struktur halaman website. Materi mencakup struktur dokumen dan penggunaan elemen dasar untuk menyusun konten.

Hasil pembelajaran

Memahami fungsi HTML dan mampu membuat struktur halaman web sederhana.

03

PERTEMUAN 3

HTML Table

Penyajian data menggunakan tabel HTML

Mempelajari tabel HTML untuk menyajikan data secara terstruktur. Pembahasan berfokus pada baris, kolom, heading, dan penggunaan tabel sesuai kebutuhan informasi.

Hasil pembelajaran

Memahami kapan tabel digunakan dan mampu menyusun data dalam bentuk tabel.

04

PERTEMUAN 4

HTML Form

Form, input, checkbox, radio button, dan dropdown

Mempelajari elemen form yang digunakan untuk menerima input dari pengguna, termasuk beberapa jenis kontrol input yang umum pada halaman web.

Hasil pembelajaran

Memahami fungsi form dan perbedaan checkbox, radio button, serta dropdown.

05

PERTEMUAN 5

Elemen Div

Menyusun struktur halaman dengan div

Mempelajari elemen div sebagai wadah atau container untuk mengelompokkan bagian-bagian halaman sehingga struktur website lebih mudah diatur dengan CSS.

Hasil pembelajaran

Memahami fungsi div dan penggunaannya dalam membangun layout halaman.

06

PERTEMUAN 6

CSS Dasar

Pengertian dan fungsi CSS

Mempelajari CSS sebagai teknologi untuk mengatur presentasi halaman web, mulai dari warna, ukuran teks, jarak, hingga tampilan elemen.

Hasil pembelajaran

Memahami hubungan HTML dan CSS serta pentingnya pemisahan struktur dan tampilan.

07

PERTEMUAN 7

Jenis-Jenis CSS

Inline, Internal, dan External CSS

Mempelajari beberapa cara menerapkan CSS pada dokumen HTML serta kelebihan penggunaan file CSS terpisah untuk pengelolaan kode yang lebih teratur.

Hasil pembelajaran

Mampu membedakan Inline, Internal, dan External CSS.

08

PERTEMUAN 8

CSS Class & Selector

Selector, class, dan pengaturan elemen

Mempelajari selector CSS untuk memilih elemen HTML yang akan diberi aturan tampilan. Class digunakan agar satu aturan dapat diterapkan pada beberapa elemen.

Hasil pembelajaran

Memahami selector dan penggunaan class untuk mengatur tampilan elemen.

09

PERTEMUAN 9

CSS Box Model

Content, padding, border, dan margin

Mempelajari konsep Box Model yang menjelaskan bagaimana ukuran dan ruang sebuah elemen HTML terbentuk dari content, padding, border, dan margin.

Hasil pembelajaran

Memahami fungsi setiap bagian Box Model dan pengaruhnya terhadap layout.

10

PERTEMUAN 10

CSS Grid Layout

Row, column, dan gap

Mempelajari CSS Grid untuk menyusun layout berbasis baris dan kolom. Properti gap digunakan untuk memberikan jarak antar item grid.

Hasil pembelajaran

Memahami dasar Grid dan mampu menyusun elemen dalam baris serta kolom.

11

PERTEMUAN 11

Responsive Web Design

Membuat website menyesuaikan ukuran layar

Mempelajari konsep responsive design agar website tetap nyaman digunakan pada desktop, tablet, maupun smartphone.

Hasil pembelajaran

Memahami pentingnya responsive design dan penerapannya pada halaman web.

12

PERTEMUAN 12

JavaScript Dasar

Membuat halaman web lebih interaktif

Mempelajari JavaScript sebagai bahasa pemrograman yang dapat memberikan perilaku dan interaksi pada halaman website.

Hasil pembelajaran

Memahami peran JavaScript dan perbedaannya dengan HTML serta CSS.

13

PERTEMUAN 13

Dialog Box

Interaksi sederhana dengan pengguna

Mempelajari dialog box untuk menampilkan pesan atau meminta respons sederhana dari pengguna melalui JavaScript.

Hasil pembelajaran

Memahami penggunaan dialog box sebagai bentuk interaksi dasar pada website.

14

PERTEMUAN 14

JavaScript Function

Function, parameter, argument, dan return

Mempelajari function sebagai sekumpulan instruksi yang dapat dipanggil kembali. Materi juga membahas parameter, argument, dan return.

Hasil pembelajaran

Memahami cara membuat function serta perbedaan parameter dan argument.

15

PERTEMUAN 15

JavaScript & Interaksi

Event dan manipulasi sederhana

Mempelajari cara JavaScript merespons tindakan pengguna dan mengubah perilaku atau bagian tertentu pada halaman website.

Hasil pembelajaran

Memahami dasar interaksi JavaScript dengan elemen halaman.

16

PERTEMUAN 16

Company Profile

Presentasi project website company profile

Pada pertemuan terakhir, kegiatan dilaksanakan melalui Zoom Meeting dengan pembahasan website company profile yang telah dibuat. Project menjadi penerapan HTML, CSS, dan JavaScript dalam sebuah website.

Hasil pembelajaran

Memahami penerapan materi perkuliahan dalam sebuah website company profile dan mampu menjelaskan bagian utama dari project.
